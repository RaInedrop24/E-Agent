# Email Template Setup Guide

## Overview

The buyer management system sends invitation emails when agents create new buyers. These emails are sent by Supabase and use customizable templates.

## Required: Configure Invite User Email Template

### Step 1: Access Email Templates

1. Go to your Supabase Dashboard: https://supabase.com/dashboard
2. Select your project
3. Go to **Authentication** → **Email Templates** (in left sidebar)
4. Find **"Invite user"** template

### Step 2: Configure the Template

Click on **"Invite user"** and customize it with the following:

**Subject Line:**
```
Your E-Agent Account - Set Your Password
```

**Email Body (HTML):**
```html
<h2>Welcome to E-Agent!</h2>

<p>Hello {{ .Data.full_name }},</p>

<p>Your estate agent has created an account for you on E-Agent Portal to manage your property transaction.</p>

<p>To get started, you need to set your password by clicking the button below:</p>

<p style="text-align: center; margin: 30px 0;">
  <a href="{{ .ConfirmationURL }}"
     style="background-color: #2563eb; color: white; padding: 12px 24px; text-decoration: none; border-radius: 6px; display: inline-block; font-weight: 600;">
    Set My Password
  </a>
</p>

<p>Or copy and paste this link into your browser:</p>
<p style="word-break: break-all; color: #666;">{{ .ConfirmationURL }}</p>

<p style="margin-top: 30px; font-size: 14px; color: #666;">
  This link will expire in 24 hours. If you didn't expect this email, you can safely ignore it.
</p>

<hr style="margin: 30px 0; border: none; border-top: 1px solid #e5e7eb;">

<p style="font-size: 12px; color: #999;">
  This is an automated email from E-Agent Portal. Please do not reply to this email.
</p>
```

### Available Template Variables

Supabase provides these variables you can use in templates:

- `{{ .Email }}` - The buyer's email address
- `{{ .ConfirmationURL }}` - Link to set password (auto-generated by Supabase)
- `{{ .Data.full_name }}` - Buyer's full name (from user_metadata)
- `{{ .Data.preferred_language }}` - Buyer's language preference
- `{{ .Data.role }}` - Always "buyer" for this template

### Step 3: Save the Template

Click **Save** to apply your changes.

### Password Recovery Template

**Location:** Authentication → Email Templates → **"Reset Password"**

**Subject:**

**Body:**
```html

<p>You requested to reset your password for E-Agent Portal.</p>
```

If users change their email address:

**Location:** Authentication → Email Templates → **"Change Email Address"**

This is less critical for the buyer flow but can be customized if needed.

## Troubleshooting Email Issues

### Email Not Received

**Check these locations:**

1. **Spam/Junk folder** - Supabase emails sometimes land here
2. **Promotions tab** (Gmail) - Check all tabs
3. **Email blocks** - Some corporate email systems block automated emails

**Check Supabase logs:**

1. Go to **Authentication** → **Logs**
2. Look for entries like:
   - `user.invited` - Should show successful invitation
   - `mail.sent` - Email was sent
   - `mail.failed` - Email failed to send (check error message)

### Common Issues

#### Issue: Email shows "undefined" for name
**Cause:** user_metadata not set correctly
**Fix:** Check that the API route passes `full_name` in the `data` object

#### Issue: Confirmation link doesn't work
**Cause:** redirectTo URL might be incorrect
**Fix:** Verify `NEXT_PUBLIC_SITE_URL` in `.env.local` is correct

#### Issue: Email template variables don't work
**Cause:** Using wrong variable syntax
**Fix:** Variables must use `{{ .VariableName }}` with double braces and capital first letter

#### Issue: No emails sent at all
**Cause:** Supabase email service not configured
**Solution:**
1. Check **Project Settings** → **Auth** → **SMTP Settings**
2. By default, Supabase uses their email service
3. For production, you may want to configure custom SMTP

### Email Delivery Limits

**Development (Free tier):**
- Supabase allows limited email sending on free tier
- Emails may be throttled
- Some email providers (like Gmail) may rate-limit

**Production:**
- Configure custom SMTP (recommended)
- Use services like SendGrid, Mailgun, or AWS SES
- Configure in **Project Settings** → **Auth** → **SMTP Settings**

## Custom SMTP Configuration (Production)

For production environments, configure a dedicated email service:

### Option 1: SendGrid

1. Sign up for SendGrid: https://sendgrid.com/
2. Create an API key
3. In Supabase: **Project Settings** → **Auth** → **SMTP Settings**
4. Configure:
   ```
   Host: smtp.sendgrid.net
   Port: 587
   Username: apikey
   Password: [Your SendGrid API Key]
   Sender Email: noreply@yourdomain.com
   Sender Name: E-Agent Portal
   ```

### Option 2: Gmail SMTP (Small Scale)

1. Enable 2FA on your Gmail account
2. Generate an App Password
3. Configure SMTP:
   ```
   Host: smtp.gmail.com
   Port: 587
   Username: your-email@gmail.com
   Password: [App Password]
   ```

⚠️ **Note:** Gmail has daily sending limits (100-500 emails/day)

### Option 3: AWS SES (Cost-Effective)

1. Set up AWS SES and verify domain
2. Create SMTP credentials
3. Configure in Supabase with SES SMTP endpoint

## Email Template Best Practices

### 1. Mobile-Friendly Design
- Use responsive HTML
- Keep buttons large (min 44px height)
- Test on mobile devices

### 2. Clear Call-to-Action
- One primary action per email
- Button text should be action-oriented ("Set My Password", not "Click Here")
- Make button visually prominent

### 3. Security Considerations
- Always mention link expiry time
- Tell users what to do if they didn't request the email
- Don't include sensitive information in emails

### 4. Branding
- Use your logo (add img tag with hosted logo URL)
- Match your application's colors
- Include footer with support contact

### 5. Accessibility
- Include plain text alternative to button (the URL below button)
- Use semantic HTML
- Ensure good color contrast

## Localization (Future Enhancement)

Currently, email templates are in English. To support multiple languages:

1. **Option A:** Use user's preferred_language to conditionally render content
   ```html
   {{ if eq .Data.preferred_language "it" }}
     <h2>Benvenuto su E-Agent!</h2>
   {{ else if eq .Data.preferred_language "de" }}
     <h2>Willkommen bei E-Agent!</h2>
   {{ else }}
     <h2>Welcome to E-Agent!</h2>
   {{ end }}
   ```

2. **Option B:** Create separate email templates per language
   - Requires custom email sending logic
   - More maintainable for complex translations
